# Praktika Clone - AI Dil Öğrenme Uygulaması

Bu proje, Praktika uygulamasının yerel çalışabilen bir klonudur. AI avatarlar ile etkileşimli dil öğrenme deneyimi sunar.

## Özellikler

- 🤖 **AI Avatar Öğretmenler**: Gerçekçi avatarlar ile birebir konuşma pratiği
- 🌍 **Çok Dilli Destek**: İngilizce, İspanyolca, Fransızca, Almanca, Bulgarca
- 🎯 **Kişiselleştirilmiş Öğrenme**: Seviyeye uygun içerik ve egzersizler
- 🗣️ **Konuşma Pratiği**: Ses tanıma ve telaffuz değerlendirmesi
- 📱 **Modern UI**: Responsive web arayüzü

## Desteklenen Diller

- 🇬🇧 İngilizce (American, British)
- 🇪🇸 İspanyolca (Spain, Latin America)
- 🇫🇷 Fransızca
- 🇩🇪 Almanca  
- 🇧🇬 **Bulgarca** (Yeni!)

## Kurulum

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev
```

## Kullanım

1. Öğrenmek istediğiniz dili seçin
2. Seviyenizi belirleyin
3. Avatar öğretmeninizi seçin
4. Konuşma pratiğine başlayın!

## Bulgarca Özel İçeriği
